# pai-adv1-final — 言葉の指示で、模倣学習した動きを組み合わせる

Physical AI 講座 2026 応用編 1 の最終課題（PAI最終課題_ogawa_one）のコードです。

Gazebo 上のロボットアーム CRANE+ V2 に、ACT（模倣学習）で覚えさせた 4 つの動き（お辞儀・うなずく・手を振る・ぱく）を、言葉の指示に応じて順に実行させます。

```
「手を振って、うなずいて、つかんで」
   → 言葉を拾って動きの並びにする   ['furu', 'unazuki', 'paku']
   → 動きごとに ACT のモデルで 20 Hz の制御
   → 終わりを判定 → 出発の姿勢へ戻す → 次の動き
```

## しくみ

- **指示 → 動きの並び**（`KeywordParser`）: 決めた言葉（「お辞儀」「うなず」「手を振」「ぱく」「つかん」など）を、文中に出てきた順に拾います。知らない言葉だけなら動かさずに終わります（終了コード 2）。`parse(text) -> list[str]` を持つものなら差し替えられるので、LLM や音声認識を入口にできます。
- **動きの実行**（`SkillRunner.run_skill`）: 観測（関節角 4 つ＋グリッパー）と、動きを始めてからの経過秒を ACT に入れ、関節の指令を 20 Hz で出します。
- **終わりの判定**: 片道の動き（お辞儀）は「出発の姿勢から 0.1 rad 以上動いた後、1 秒間止まった」ら終わりです。往復の動き（うなずく・手を振る・ぱく）は「出発の姿勢に戻って、観測と指令の両方が 1 秒止まった」ら終わりです。上限は 60 秒です。
- **出発の姿勢へ戻す**: 動きの間に、腕を直立に、グリッパーを記録のときの「開」（−0.5236 rad）に戻し、着いたことを確かめてから次の動きに進みます。
- **安全の確認**: ほかのノード（テレオペなど）が腕に指令を出しているときは、動かさずに止まります。

## 4 つの動き

| 名前 | 動き | 記録 | コマ数（20 Hz） |
|---|---|---|---|
| `pekori` お辞儀 | 関節 3 を前へ倒す（片道） | 10 本 | 3,000 |
| `unazuki` うなずく | 関節 4 を 0 → +0.5 → 0（往復） | 10 本 | 2,740 |
| `furu` 手を振る | 関節 2 を 0 → +0.3 → −0.3 → 0（0 を通る往復） | 11 本 | 4,290 |
| `paku` ぱく | グリッパーを 1 回閉じて開く | 10 本 | 2,620 |

記録はテレオペ（キーボード）で Gazebo のロボットを動かして取りました。どの動きも同じ設定で学習しています。

- ACT（LeRobot）・CPU・バッチ 16・1,800 ステップ・`chunk_size` 16
- 入力に「動き出してからの経過秒」を足す（`observation.environment_state` を 1 値にする）
- 関節角の正規化に使う標準偏差に下限 0.1 rad を置く
- 学習時間は 1 本 15〜19 分、メモリは最大 3.4 GB（Gazebo を止めて学習）

## 工夫した点

1. **経過時間を入力に足した**: 入力が関節角だけのモデルは、往復の動き（行きと帰りで同じ角度を通る）を区別できず、直立から 0.010 rad しか動きませんでした。動き出す前の待ちを切り落とし、経過秒を入力に足すと、往復を覚えました（`adv1_rosbag2lerobot_time.py`）。
2. **正規化の標準偏差に下限を置いた**: 記録で動かない関節は標準偏差がほぼ 0（1e-6 以下）になり、前の動きの残り（0.001 rad 程度）が何百倍以上に拡大されて、続けて動かすと止まりました。下限 0.1 rad を置いて学習し直しました（`adv1_train_skill.sh` の 5 番目の引数）。
3. **お辞儀は予測をまとめて実行する**: 毎回予測し直すと、指令が「いまの角度」に張り付いて止まりました。予測した 0.8 秒分（8 個）をまとめて実行するように直しました（`Skill.chunk_steps`）。
4. **Gazebo なしの照合**: 学習に使った記録のコマをそのままモデルに入れ、記録の指令と比べました（`adv1_offline_check.py`）。Gazebo で動かす前に、学習そのものの問題かを切り分けられます。

## ファイル

| ファイル | 役割 |
|---|---|

| `adv1_run.sh` | コンテナの中で環境（ROS・pixi）をそろえて本体を呼ぶ |

## 動かし方

前提（講座の第 5 回の演習環境）:

- Docker イメージ `airobotbook/ros2-desktop-ai-robot-book-humble`（ROS 2 Humble・Gazebo・CRANE+ V2）
- [`matsuolab/pai_training`](https://github.com/matsuolab/pai_training)（`~/pai_training`・pixi の環境。変換と学習）
- [`matsuolab/physicalai_teleop`](https://github.com/matsuolab/physicalai_teleop)（`~/pai_ws`。記録のときのテレオペ）

このリポジトリのファイルは、コンテナの中の `/home/ubuntu/adv1/` に置く前提です。記録は `~/dataset/rosbags/<動きの名前>/` に、モデルは `~/checkpoints/train/` に置きます。学習済みモデル（1 本約 160 MB）と記録は、このリポジトリに入れていません。

```bash
# 1 つの動きを学習する（例: うなずく。経過時間あり・1,800 ステップ・バッチ 16・標準偏差の下限 0.1）
bash /home/ubuntu/adv1/adv1_train_skill.sh unazuki time 1800 16 0.1
#   → ~/checkpoints/train/crane_plus_unazuki_t_s1800_b16_f_act

# Gazebo を起動した後（テレオペは止めておく）、言葉の指示で動かす
bash /home/ubuntu/adv1/adv1_run.sh "手を振って、うなずいて、つかんで"
```

終了コードは、0 = すべての動きが終わって出発の姿勢に戻った、1 = 時間切れなど、2 = 知っている動きの言葉が無い、です。1 歩ごとの記録（CSV）は `--log-dir` に書かれます。

## 結果と、うまくいかなかったこと

- 動画では 4 つの指示を順に実行しています。「お辞儀して」「手を振って、うなずいて、つかんで」「ぱくぱくしてからお辞儀して」は最後まで実行し、「ジャンプして」は知らない言葉なので動きません。
- 学習に使った記録での照合（平均誤差 rad）は、お辞儀 0.014、うなずく 0.036、手を振る 0.020、ぱく 0.147 です。
- **ぱく**は、記録では「閉 → 開 → 閉 → 開」ですが、モデルは 1 回目の「閉 → 開」しか再現しません。そのため「1 回閉じて開く」動きとして使い、「ぱくぱく」は 2 回続けて実行します。
- **学習量**: バッチ 2 のままステップ数を増やしても、手を振るは記録の動きになりませんでした（1,000 ステップで 0.068、3,000 ステップで 0.081）。バッチ 16・1,800 ステップ（見るサンプルが約 4.8 倍）にすると 0.027 まで下がりました。
